# Aplicación Calclin — Especialización en Desarrollo con IA Generativa (Accenture)

## Aplicación para el cálculo de una linea  de transmisión eléctrica con ayuda de un modelo de inteligencia artificial generativo para verificar que el diseño se ajusta a las normas sísmica, de resistencia al viento y otras relativas al tipo de estructura que se considera.

La aplicación considera dos modelos generativos LLM: 
Gemini-3.8-flash: mas lento pero entrega resultados mas completos y con un costo por token mayor.
Gemini-3.5-flash-lite: mas rápido con resultados mas resumidos y un costo por token menor

Para probar la aplicación se considero el uso del modelo mas liviano, lo cual esta considerado en el archivo main de inicio de la aplicación.
